## 方法与输入

主要对比为：单 GPS、固定权重融合、自适应抗异常融合、公开 KF-GINS。另有固定噪声 KF、去 IMU、去自适应噪声、去异常抑制、去延迟补偿，以及 FilterPy 原版实现校验。

核心状态为 `[E,N,U,vE,vN,vU]`。原始 IMU 传播姿态、去除重力并预测运动；GPS 位置与接收器速度用于更新。固定融合采用锁定权重。改进方法按水平位置创新的 NIS 调整位置观测噪声，在严重异常时抑制位置更新并保留速度更新；有真实测量时标的迟到 GPS 按接收器速度传播到到达时刻。惯性加速度采用固定范数保护，IMU 超过 0.35 秒不可用时回退到匀速预测、增大过程噪声。

各项消融保持其他机制和参数一致。`kf_fixed` 是关闭全部鲁棒更新机制的参考，`no_adaptive` 才是单独去掉自适应噪声的消融；两者不混用。FilterPy 与自实现固定 KF 的独立一致性检查用于检验实现，不作为新的算法创新。

原版 KF-GINS 仅使用 GNSS 位置更新，不接收连续 GPS 速度观测。因此另设严格的“仅位置更新”对照：核心方法关闭速度观测的影响（速度标准差设为 10^8m/s、固定融合速度权重为零），单 GPS 采用位置保持，复用相同初始化与参考时刻，并验证开始后将速度字段改变 1000m/s 对自适应输出的影响小于 10^-7。KF-GINS 的对比结论优先依据这个表。不得把主表中输入字段差异带来的效果全部归因于鲁棒机制。

## 数据审计与评价规则

保留整数微秒时标，先审计再稳定排序；发现 GPS 六处时间倒序。原始 IMU 各 27,050 行，约 10Hz；GPS 日志 81,169 行，包含逐图像复制的接收器读数。统一取至少 1 秒间隔的 GPS 观测，不把 30Hz 表格行数当成独立定位解频率。加速度与不晚于它的最近陀螺仪样本匹配，容差 0.15 秒。

经纬度按包内实际数值读取为度，GPS 高度按实际数值读取为米；原 README 的缩放文字与实际 CSV 有差异。水平坐标转换为 EPSG:32632，并减去共同 GPS 原点，不对每种方法进行事后轨迹配准。位置真值按图像编号关联原始 GPS 时标；两个尾部超范围编号单独列出，不强行插值匹配。真值仅用于调参和评价，估计函数不读真值文件或相机真值姿态。

采用原始 IMU 的 FRD 体轴、NED 姿态传播及 m/s²、rad/s 单位作为显式建模假设。初始横滚、俯仰来自此前五秒加速度；速度足够时按 GPS 航迹角近似初始偏航，否则记录不可观测；满足低动态条件才估计初始陀螺仪零偏。没有使用 `OnboardPose.csv` 的已有融合输出。这些假设没有获得完整历史固件、安装外参或独立标定的确认。

固定的调参片段为 7—67 秒。四个测试片段仅按连续性和真值覆盖选择，分布在 413—473、1154—1214、1894—1954、2625—2685 秒；没有依据测试误差挑选。参数只在早期片段上搜索并锁定；测试不参与选择。自实现和公开方法的调参表分别保留。

每段有 62 个场景、9 种实现/配置，共 2232 次核心运行。包含 GPS 缺失 1/3/5 秒、GPS 三维位置噪声 1/3/5m、到达延迟 0.2/0.5/1 秒、水平突发偏差 10/20/50m、IMU 缺失 1/3/5 秒、IMU 加速度噪声 0.2/0.5/1m/s²，并按比例加入角速度噪声。随机条件使用五个固定种子。组合场景覆盖 GPS 缺失加位置噪声、位置噪声加延迟、GPS 缺失加 IMU 噪声、突发偏差加延迟。GPS 噪声实验保持接收器速度字段不变；它表示位置通道扰动，不代表所有 GNSS 通道同时退化。延迟实验表示“测量时标正确、到达变晚”，不能等同于未知时钟偏移校准。

原版 KF-GINS 在正常、GPS 缺失、位置噪声、突发偏差 25 个场景上运行四段，共 100 次；没有宣称它参加原实现不支持的迟到队列及 IMU 缺失对比。仅位置协议增加 400 次控制实验，合计 2732 次正式运行，不计调参、计时、单元检查、demo 与官方示例。

在原始真实参考时刻评价水平 RMSE、P95、中位数、三维 RMSE 和垂向 RMSE，并单独统计缺失及恢复阶段。只将已经得到的状态按已知速度作因果传播，不使用未来状态平滑。KF-GINS 原生输出先因果投影到统一 0.1 秒输出网格，最大允许原生状态年龄 0.35 秒。表格的均值是各路段/随机条件 RMSE 的算术平均；P95 也是逐次运行 P95 的平均，误差条为跨路段/重复的标准差，不是置信区间。

## 加分项与复现证据

1. **公开基线**：实际运行原版 [KF-GINS](https://github.com/i2Nav-WHU/KF-GINS)，锁定提交 `8291a93e49de513fe9d21f819500d39082ded611`，保留 GPLv3 许可证、原始代码、来源哈希、配置和终端记录。官方示例复现范围是 456300—456360 秒子集，不是完整复现论文所有表格。将 AGZ 瞬时原始 IMU 转换为前一已知样本零阶保持积分得到的增量，这是数据适配假设，不能称为传感器原生增量。缺少杆臂标定时采用零杆臂；给出的高度按一致基准数值使用，未完成独立高程基准校准。
2. **效率**：在同一杭州服务器上固定单线程，每种 Python 实现使用独立进程，预热后重复五次。核心计时含姿态、状态传播、GPS 更新和输出构造，排除读盘、扰动生成、评分和分位数汇总。进程峰值内存包括解释器、依赖和已加载日志；跟踪分配峰值另列，避免将两者混同。正式共享服务器的调度波动保留在重复测量中。
3. **可视化**：二维/三维轨迹、时序误差、经验分布、单扰动、组合扰动、消融、效率图，以及可离线操作的轨迹回放。
4. **多鲁棒性**：两种模态分别缺失、多种噪声强度、异常值、异步到达与四类组合干扰，五种子重复及失败场景分析。

## 结论边界

严格位置更新对照中，改进方法在较大位置噪声下存在明显失稳，详见结果说明和第九组图。完整性检查中的零失败仅指无执行/非有限数值错误，100% 参考时刻覆盖仅表示有输出，均不代表定位始终可靠。

以实际结果说明适用条件，不保证融合或改进方法在每个片段都优于单 GPS。该数据的低频惯性日志、未知安装外参和初始航向近似限制了惯性导航能力；真值是摄影测量重建的相机位置，使用 GPS 初值，并非完全独立的外部运动捕捉。相机与 GPS/IMU 安装点杆臂未补偿。三维与垂向结果保留作诊断，不能宣称已校准绝对高程。测试覆盖四个连续路段，不能外推为整条航线的无缝导航表现。
